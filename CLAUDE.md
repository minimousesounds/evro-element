# Кама-фильтр (бывший «Евроэлемент»): новый сайт

Сайт магазина автофильтров (отец пользователя), Набережные Челны. Старый сайт на закрытой CMS студии «Вебцентр», исходников нет.

## Решения
- Статический сайт на Astro, админка Sveltia или Decap поверх GitHub, один товар = один файл.
- Клиент покупает на сайте: корзина → оформление → письмо отцу. Онлайн-оплаты нет.
- ООО «Евроэлемент» больше нет (15.10.2026). Магазин переименован в «Кама-фильтр» (название в site.json `name`, логотип берёт его оттуда), новый домен kama-filtr.ru куплен 15.10.2026 в новом аккаунте REG.RU (почта отца). evro-element.ru остаётся и ведёт 301 на новый: правила генерирует `src/pages/old-domain.htaccess.ts` (в сборке `dist/old-domain.htaccess`), при выкладке кладётся в папку старого домена как `.htaccess`. Доступа к старому аккаунту REG.RU нет (письмо восстановления не приходит), DNS evro-element.ru на Beget. Счета выставляют ИП Шафигуллин А. Ф. (с НДС) и «Кама-фильтр» (без НДС). Продавец на сайте берётся из site.json (`legalName`, `inn`, `ogrn`), организация-покупатель на оформлении выбирает счёт с НДС или без.
- ASAS на сайте не упоминаем совсем (решение владельца, 15.10.2026): ни в текстах, ни в бренде товара (у бывших ASAS бренд пустой, kind analog), страницы техинформации ASAS удалены. Импорт и бот бренд ASAS не записывают. Что аналог — говорим прямо, без названия оригинального бренда.
- SEO: ЧПУ, title и description из данных, schema.org, sitemap, 301 со всех старых адресов. На старом сайте у каталога и товаров стоит `noindex`, в новом его быть не должно.
- Дизайн: Figma `Jb1g2YpPyBAlntrNwYeBtO` (Onest, JetBrains Mono для артикулов, акцент #FFCC00).

## Сайт (Astro 7)
- Команды и структура описаны в README.md. Локальный просмотр: preview «evro-element», порт 3330.
- Схема данных: `src/content.config.ts`. Товар: title, sku, brand, kind (original, analog или пусто), category, price, inStock, popular, offer, images, replaces, specs, country, applicability, seoTitle, seoDescription.
- Адреса: `/catalog/<категория>/<артикул>/`, `/tech/<старый слаг>/`, `/about/`, `/contacts/`, `/privacy/`, `/terms/`, `/consent/`, `/cookies/`.
- Корзина хранится в localStorage (`src/scripts/cart.ts`), поиск работает в браузере (`src/pages/search.astro`).
- В разметке Product бренд указывается только если товар не аналог.
- Админка: Sveltia CMS, `public/admin/`. Бесплатная, работает поверх GitHub.
- Каталог (15.10.2026) загружен из прайса отца для Автопитера: `python scripts/import_price.py "<прайс>.xls"` (нужен `pip install xlrd`). Скрипт обновляет совпавшие по артикулу товары, создаёт новые, скрывает отсутствующие (`hidden: true`, файл не удаляется) и пересчитывает редиректы. Повторный запуск безопасен. Поля товара `unit` (шт./компл.) и `minQty` (минимальная партия, степпер не даёт меньше). Категории без видимых товаров сайт не показывает сам. Колонка прайса со ссылкой на Росаккредитацию одинакова у всех строк, это не декларация конкретного товара, поэтому не выводим.
- Контент создан скриптом `scripts/import_content.py`. Повторный запуск не трогает существующие файлы, `--force` перезаписывает.
- Вёрстка по макетам Figma сделана 14.10.2026 (шапка с мега-меню и боковым меню, модалка звонка, все страницы в трёх ширинах). Тексты «О компании» лежат в `src/data/about.json` и правятся в админке (Настройки → Страница «О компании»).
- Оплата (15.10.2026, со слов отца): в основном по счёту, и для организаций, и для частных покупателей. На оформлении два способа: «По счёту» (по умолчанию, почта обязательна) и «При получении в офисе» (только при самовывозе).
- Количество в корзине: в карточке после «В корзину» появляется степпер, связанный с корзиной (`[data-cart-ctl]` в `src/scripts/cart.ts`), число можно вписать с клавиатуры.
- Заказы уходят через Web3Forms. OG-картинка и иконки выгружены из Figma (страница «Ассеты»). Не настроено: боевой хостинг и домен.

## Репозиторий и выкладка
- GitHub: https://github.com/minimousesounds/evro-element (публичный). gh CLI: `C:\Program Files\GitHub CLI\gh.exe`, в Git Bash добавить в PATH.
- Автор коммитов — анонимный адрес GitHub (noreply), настоящую почту не светим.
- `.github/workflows/deploy.yml` выкладывает копию на GitHub Pages с SITE_URL, SITE_BASE=/evro-element/ и PUBLIC_PREVIEW=1 (noindex и robots Disallow).
- Ссылки в шаблонах пишем от корня, в подпапке их дописывает интеграция prefix-base в astro.config.mjs. В скриптах использовать import.meta.env.BASE_URL.
- Локальная сборка под подпапку в Git Bash: `MSYS_NO_PATHCONV=1 SITE_BASE=/evro-element/ ...`, иначе путь превращается в путь на диске.

## Боевой хостинг
- Beget, платный тариф (420 ₽/мес), аккаунт o92745df на почту отца, сервер 87.236.19.212 (бесплатный сервер 185.50.25.55 резал зарубежные запросы). Папка сайта `o92745df.beget.tech/public_html`, к ней прилинкован kama-filtr.ru, DNS домена на Beget.
- Выкладка: `.github/workflows/beget.yml`, FTP-Deploy по FTPS по одному файлу (параллельный lftp терял файлы), секреты BEGET_FTP_*, переменная BEGET_DIR=./ (FTP-аккаунт o92745df_deploy смотрит в public_html).
- `.htaccess` собирает сайт: `src/pages/main.htaccess.ts` (www → без www, https при `forceHttps: true` в site.json, старые адреса). В `public/` файла нет, скрипты и бот пишут только redirects.json.
- Из-за границы сайт открывается; бот берёт bot-index.json с копии на GitHub Pages.

## Папки
- `scrape/` — парсер старого сайта. `scrape.py` (товары, категории, страницы, фото), `annotate.py` (разметка старых адресов), `page_images.py` (картинки техстраниц). `raw/` — кэш HTML, повторный запуск сеть не трогает.
- `data/` — результат парсинга от 03.10.2026:
  - `products.json`, `products.csv` — 74 товара;
  - `categories.json` — 10 категорий;
  - `images/` — 25 фото товаров;
  - `pages/` — тексты страниц (`.md` и исходный `.html` контентного блока), `pages.json` — индекс;
  - `page-images/` — 162 картинки из техстраниц;
  - `old-urls.csv` — 385 старых адресов с колонкой `action`, колонка `new_url` пока пустая.

## Что известно о данных
- У товара есть только название, артикул, бренд, цена, категория и иногда фото. Описаний и характеристик нет.
- Фото есть у 25 товаров из 74. Сервер отдаёт фото с кодом 404, парсер это учитывает.
- Бренды: ASAS 39, остальные 35 (HiFi Filter, Claas, Mann+Hummel, Perkins и другие). В поле «бренд» встречаются «Россия», «Китай», «не указан».
- В названиях 18 товаров уже есть слово «аналог», в 3 «оригинал».
- Раздел `affiliation*` (197 страниц) — обмен ссылками студии, не переносим.
- 90 страниц техинформации (каталоги ASAS, китайские авто, катки DYNAPAC, техника KOMATSU и VOLVO), 63 с таблицами.
- В старой разметке товаров вшиты выдуманные рейтинг и отзывы. В новый сайт их не переносим.
